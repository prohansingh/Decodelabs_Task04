# Decodelabs_Task04
Project-4-Data Visualization and Storytelling


## Project Overview

This project focuses on data visualization and storytelling using an E-commerce Sales Dataset. The main objective of this project is to analyze business data and create meaningful visualizations that help identify trends, customer behavior, product performance, and business insights.

The project was completed using Python for data cleaning and exploratory data analysis (EDA), and Tableau for dashboard creation and storytelling visualization.

---

# Objective

The objective of this project is to:

- Perform data cleaning and preprocessing
- Analyze sales and customer data
- Create meaningful visualizations
- Develop an interactive dashboard
- Generate business insights and recommendations
- Apply data storytelling principles

---

# Tools and Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Tableau
- Microsoft Excel

# Dataset Information

The dataset used in this project contains E-commerce sales and order information.

## Dataset Features

- Product Details
- Quantity
- Total Price
- Payment Method

- Referral Source
- Date Information
- Customer Purchase Data

# Project Workflow

## Step 1 – Data Collection

The dataset was collected and imported into Python for preprocessing and analysis.

---

## Step 2 – Data Cleaning

The following preprocessing steps were performed:

- Removed duplicate values
- Checked missing values
- Converted date columns
- Created month and year columns
- Verified data consistency

---

## Step 3 – Exploratory Data Analysis (EDA)

EDA was performed to understand trends and patterns in the dataset.

The following analyses were performed:

- Monthly Sales Analysis
- Product Performance Analysis
- Payment Method Analysis
- Order Status Analysis
- Referral Source Analysis
- Quantity Distribution Analysis

---

## Step 4 – Data Visualization

Different visualizations were created to represent business insights clearly.

### Visualizations Created

- Monthly Sales Trend
- Top Selling Products
- Payment Method Analysis
- Order Status Distribution
- Referral Source Performance
- KPI Cards

---

## Step 5 – Dashboard Creation

An interactive dashboard was created in Tableau to combine all visualizations and KPIs into a single business storytelling dashboard.

### KPI Cards Included

- Total Sales
- Total Orders
- Total Quantity
- Average Order Value

---

# Data Storytelling Principles Applied

The dashboard was designed using storytelling principles such as:

- One chart focuses on one insight
- Use of action-oriented titles
- Minimal and clean design
- Highlighting important insights
- Avoiding unnecessary chart elements

---

# Key Insights

- Electronics products generated the highest revenue.
- Most customers preferred online payment methods.
- Sales increased during peak shopping months.
- Referral sources such as Instagram and Google contributed significantly to orders.
- Most orders were successfully delivered with a smaller percentage of cancellations and returns.

---

# Recommendations

- Increase marketing efforts on high-performing referral platforms.
- Improve customer support to reduce order cancellations.
- Focus more on top-performing products.
- Optimize inventory management during high-sales periods.
- Enhance promotional campaigns during festive seasons.
